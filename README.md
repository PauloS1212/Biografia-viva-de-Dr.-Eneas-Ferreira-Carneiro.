# Biografia-viva-de-Dr.-Eneas-Ferreira-Carneiro.
Nesse projeto é analisar a vida, os ideais, os trabalhos e propostas desse antigo candidato na política brasileira. Meu objetivo é entender esse homem e compreender se ele era um dos únicos/melhores políticos do Brasil. Sua jornada pode inspirar e servir de base para criticarmos os atuais presidentes nessa eleição de 2026.
